# Controlled Elements (elementos controlados)

Son una forma de hacer que React controle el valor de un elemento HTML, como un `input`, en lugar de dejar que el DOM sea quien mantenga ese valor por su cuenta.

## ¿Qué problema resuelven los Controlled Elements?

Por ejemplo tenemos un campo de texto:

``` javascript

<input type="text" />

```

Podemos escribir un nombre y el navegador se encarga de mostrarlo en el campo. El DOM mantiene el valor que hemos escrito.

Pero ¿qué pasa si queremos que React conozca ese valor para utilizarlo en otras partes de la aplicación? Por ejemplo, para mostrar el nombre debajo del campo o para validar lo que escribimos.

**Ahí entran los Controlled Elements**.

La idea es que **React almacene el valor en el state y que el elemento HTML muestre ese valor.**

## Paso 1. Definir el estado

Primero, creamos una variable de estado con useState.

``` javascript

const [name, setName] = useState("");

```

Esto significa:

- `ame`: contiene el nombre actual.

- `setName`: permite actualizar ese nombre.

- `""`: el valor inicial es una cadena vacía.

Inicialmente, el usuario todavía no ha escrito nada.

## Paso 2. Usar el estado en el elemento que queremos controlar

Ahora usamos `name` en la propiedad `value` del `input`.

``` javascript

<input
  type="text"
  value={name}
/>

```

La parte importante es:

``` javascript

value={name}

```

Esto le dice a React que el valor mostrado en el campo debe corresponder al estado `name`.

Si `name` = "Pepe", el campo mostrará "Pepe".

## Paso 3. Actualizar el estado

Para actualizar `name` cada vez que el usuario escribe, utilizamos el evento `onChange`.

``` javascript

onChange={(e) => setName(e.target.value)}

```

- `onChange`: se ejecuta cuando cambia el valor del campo.

- `e`: representa el evento que ocurrió.

- `e.target`: hace referencia al elemento HTML que generó el evento, en este caso, el input.

- `e.target.value`: contiene el texto que el usuario escribió.

- `etName(...)`: actualiza el estado con ese texto.

Ejemplo:

``` javascript

import { useState } from "react";

export default function App() {
  const [name, setName] = useState("");

  return (
    <div>
      <label htmlFor="name">Tu nombre:</label>

      <input
        id="name"
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
      />

      <p>Hola, {name || "desconocido"}</p>
    </div>
  );
}

```

## Flujo Completo

Cuando escribimos la letra `B`, ocurre este flujo:

1. El usuario escribe `B`
        
2. Se dispara `onChange`

    `e.target.value` contiene `B`

3. Se ejecuta `setName("B")`

    React actualiza el estado

4. React vuelve a renderizar

    `value={name}` ahora recibe `B`

Cuando escribimos algún nombre, el proceso se repite con cada cambio. React mantiene el estado sincronizado con el campo.

## ¿Qué diferencia hay entre un elemento controlado y uno no controlado?

| Elemento  | ¿Quién mantiene el valor? |
|:--------- | ---------:
|No controlado | Principalmente el DOM
|Controlado  | El estado de React |


Un campo controlado se reconoce normalmente por esta combinación:

``` javascript

<input
  value={state}
  onChange={(e) => setState(e.target.value)}
/>

```

**Importante**: el DOM sigue existiendo y el navegador sigue gestionando la interacción física con el campo. Lo que cambia es que React, a través del estado, es la fuente de verdad del valor mostrado.

## ¿Para qué sirve esto en proyectos?

- Los elementos controlados son especialmente útiles para:

- Formularios de registro e inicio de sesión.

- Validar correos electrónicos y contraseñas.

- Habilitar o deshabilitar botones según lo escrito.

- Mostrar búsquedas en tiempo real.

- Actualizar otros componentes a medida que el usuario escribe.

### En resumen:

- **Definir el estado**: `const [name, setName] = useState("")`;

- **Vincular el estado al elemento**: `value={name}`

- **Actualizar el estado cuando cambia el elemento**: onChange=`{(e) => setName(e.target.value)}`

La idea fundamental es que el estado de React determina el valor del campo, y los eventos permiten actualizar ese estado.
