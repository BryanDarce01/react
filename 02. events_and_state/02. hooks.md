# ¿Qué es un Hook?

Exactamente: las funciones de React que empiezan con:

    use...

son Hooks.

Por ejemplo:

``` javascript

useState()
useEffect()
useContext()
useReducer()
useRef()
useMemo()
useCallback()

```

son Hooks.

No significa simplemente que cualquier función cuyo nombre empiece con `use` sea automáticamente un Hook.

React define Hooks específicos y también podemos crear nuestros propios **custom Hooks**, que por convención empiezan con `use`.

En otras palabras:

- Un Hook es una función especial de React que permite que un componente funcional utilice determinadas capacidades de React.

`useStat` → permite trabajar con estado.

`useEffect`→ permite sincronizar el componente con sistemas externos y ejecutar efectos secundarios.
